# LockFree

## 개요
이 폴더는 멀티스레드 환경에서 동기화 비용을 줄이기 위해 구현한 Lock-Free 자료구조를 포함하고 있습니다.  
CAS(Compare-And-Swap) 기반의 원자적 연산을 활용하여 락 없이 동시 접근을 처리하는 구조로 구성했습니다.

---

## 역할
- 공용 자원에 대한 동시 접근 처리
- 락 사용 없이 안전한 자료구조 제공

---

## 구성

- Lock-Free Queue
- Lock-Free Stack
- Max Lock-Free Queue

---

## 특징

- CAS 기반으로 동기화 처리
- 락 없이 다중 스레드 접근 가능

---

## 고려 사항

- ABA 문제와 같은 Lock-Free 특유의 이슈 존재
- 메모리 관리 및 안전성에 대한 추가 설계 필요

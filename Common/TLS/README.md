# TLS

## 개요
이 폴더는 스레드 로컬 저장소(Thread Local Storage)를 활용한 메모리 관리 구조를 포함하고 있습니다.  
각 스레드가 독립적으로 메모리를 관리하도록 하여 동기화 비용을 줄이기 위해 구성했습니다.

---

![TLSMemoryPool](../../Images/TLSPool.png)

---
## 역할
- 스레드별 메모리 할당 관리
- 공용 자원 접근 시 발생하는 경합 감소

---

## 구성

- TLS 기반 메모리 풀
- 스레드 단위 메모리 관리 구조(TLSDBConnector, TLSRedisConnector)

---

## 특징

- 각 스레드가 자체적으로 메모리를 관리하여 경합 최소화
- 멀티스레드 환경에서 메모리 할당 성능 향상
- 필요 시 공용 메모리 풀과 연계 가능
